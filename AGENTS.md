# slicc-ortllama

Local ONNX model server with OpenAI-style APIs (issue #2). Same code in slicc-kernel under jsh (`onnxruntime-web` via the `slicc` condition of `#ort`) and on host Node (`onnxruntime-node`). Models come only from the Hugging Face cache. Engines live in `src/engines/`, receive ORT injected, and implement `detect`, `missing`, `include`, `load`, `checkOverrides`, `check`. Node ≥ 24, ESM. Lint with `slicc-lint`. No comments in any file. Agent guidance lives only in this AGENTS.md (≤1000 characters). Do not add CLAUDE.md. Unit tests stay in gitignored `test/unit/` and must cover every staged line of `src/`. Integration tests in `test/integration/` are committed. Publish from `main` with semantic-release and fledgling trusted publishing (`release.yml`).
