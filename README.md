# slicc-ortllama

Empty package for SLICC's built-in ort-llama server: ONNX Runtime with models loaded from OPFS, and OpenAI-compatible (and other) APIs on a fake localhost that the service worker intercepts.

```js
import {} from '@ai-ecoverse/slicc-ortllama';
```

Node ≥ 24. `npm run lint` runs `slicc-lint`. Releases use semantic-release on `main`.
